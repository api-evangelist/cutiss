# CUTISS

> CUTISS AG is a Swiss late-stage clinical TechBio company in Schlieren, Zurich, founded in 2017 as a
> spin-off of the Tissue Biology Research Unit at the University of Zurich and the University Children's
> Hospital Zurich. Its lead product denovoSkin is a bioengineered, personalized dermo-epidermal skin
> graft grown from a patient's own biopsy to treat large and deep skin defects, with Orphan Drug
> Designation for burns from Swissmedic, the EMA and the FDA. With CSEM it built denovoCast, the first
> machine for automated production of personalized human skin tissue.

CUTISS is a therapeutics manufacturer, not a software vendor. It publishes no product API, no developer
portal, no SDK, no CLI, no pricing and no API documentation. The only machine-readable API on its public
host is the WordPress REST API serving cutiss.swiss, which returns the company's newsroom, blog,
corporate pages, team directory and media library as JSON.

This file was generated by API Evangelist from probed artifacts. CUTISS does not publish an llms.txt of
its own (https://cutiss.swiss/llms.txt returns 404).

## Access

- Anonymous read only. No credential is required, offered or issuable — there is no developer sign-up.
- Every write method and every administrative collection returns HTTP 401 `rest_forbidden`, including `/users`, `/settings`, `/plugins`, `/menus` and `/wp-abilities/v1/*`.
- No OAuth and no OpenID Connect: `/.well-known/oauth-authorization-server` and `/.well-known/openid-configuration` both return 404.
- No MCP server. `/wp-json/mcp` returns 404 `rest_no_route`; the `wp-abilities/v1` registry is present but 401-gated.
- No A2A agent card, no security.txt, no api-catalog — every `/.well-known/` path returns 404.

## Conventions

- Pagination: `page`, `per_page` (max 100, larger values return 400), `offset`; totals in the `X-WP-Total` and `X-WP-TotalPages` response headers plus an RFC 5988 `Link` header.
- Filtering: `search`, `slug`, `include`, `exclude`, `after`, `before`, `modified_after`, `modified_before`, `categories`, `order`, `orderby`.
- Sparse fields with `_fields`; relation inlining with `_embed`.
- Errors use the WordPress `{code, message, data.status}` envelope, not RFC 9457. Messages are returned in German — branch on `code`.
- No rate limit is published and no `X-RateLimit-*` or `Retry-After` header is returned. Self-throttle.
- No idempotency support; the public surface is read-only.
- Bilingual via Polylang: English and German objects are separate records with distinct ids, so counts above include both trees.
